# Keepa

Keepa 多年来一直在记录亚马逊商品的数据。装上这个插件，cx 就能替你查这些历史：商品每天的价格、销售排名（BSR）、Buy Box 归属、报价、优惠券和月销量预测，覆盖亚马逊美国、英国、德国、法国、日本、加拿大、意大利、西班牙、印度、墨西哥和巴西站。

亚马逊页面只显示今天的数据。Keepa 能看到之前发生了什么，所以 cx 可以回答这样的问题：

- 我的排名是从哪一天开始下滑的？那天价格、Buy Box 或库存有什么变化？
- 某个搜索词下哪些商品卖得最好？它们的价格、评分和月销量各是多少？
- 这个商品现在的销量比去年同期高还是低？

cx 可以按 ASIN 或商品名称查找商品。给出名称时，cx 会先搜索，核对找到的商品标题和型号；如果有多个商品都符合，会请你选择。

## 费用

cx 每读取一个商品，都会从你的 ComChatX 余额扣款。插件页面会显示读取一个商品的价格，「用量」页列出每一笔购买和费用。

## 依赖

Keepa 会和 cx-sources 一起安装，cx-sources 负责替 cx 购买和读取数据。
